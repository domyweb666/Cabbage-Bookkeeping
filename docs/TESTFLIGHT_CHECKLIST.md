# TestFlight 實測清單

這些要在真的手機上試。每一項寫了怎麼做、看到什麼算過。

測試資料要清掉的話，最後再做「清除所有資料」那兩項。

## 記

- [ ] 第一次打開：刪掉 App 重裝再打開。沒有教學、不用登入、不跳權限，直接看到「還沒有紀錄」和底部的「記一筆」。
- [ ] 記一筆：按「記一筆」，按 1、8、8，點「飲食」，按「記下」。明細最上面出現這筆，提示條寫「記好了。飲食這個月共 NT$188」，本月支出多 188。從點開 App 到記好，8 秒內算過。
- [ ] 沒填完不能記：只按金額，或只點分類，「記下」都按不動。
- [ ] 金額鍵盤：「00」和退格都正常。一直按，最多到八位數。
- [ ] 按住退格：打八位數，按住退格會一直刪到 0。短按一下只刪一位。
- [ ] 打字的速度：快速打「1500」「38」「12000」，數字一按就出現，每一鍵都看得出按到。跟 iPhone 的計算機並排比。
- [ ] 兩隻拇指交替快打「1234567890」十次，只看前八位，數漏了幾個。
- [ ] 記好的震動：重開 App 記第一筆，之後停十秒再記一筆。震動跟提示條、明細多一筆是同一刻。
- [ ] 左滑刪除：慢慢滑刪五次，一口氣滑到底五次，不會頓一下。
- [ ] 鍵盤切換：點備註和按「完成」各錄影慢放，日期備註那一列直接滑過去，不會先掉下去再被推上來。
- [ ] 連續記三筆：記完一筆馬上再記兩筆，三筆都在，最新的在最上面。
- [ ] 收入：切到「收入」，分類換成薪水、獎金、投資、其他收入。記薪水 42000。明細是綠色的 +42,000，本月支出不變。
- [ ] 切換收入和支出：選好飲食後切到「收入」，再切回「支出」，飲食要變成沒選。
- [ ] 備註：點備註，數字鍵盤讓位給系統鍵盤，用注音打「加油」，按「完成」，數字鍵盤回來。記下後明細標題是「加油」，下面的小字是分類。
- [ ] 不填備註：明細標題直接是分類名。
- [ ] 一次性：支出點「一次性」，下面出現「跟平常比的時候，不算這一筆。」記下後明細有「一次性」。切到收入時沒有這顆。
- [ ] 補記：日期選昨天，這筆排到「昨天」。明天以後的日期選不到。
- [ ] 補記上個月：日期選上個月，記一筆飲食。提示條寫「記好了。飲食 NT$…」，沒有「這個月共」，本月支出不變。
- [ ] 取消：填到一半按「取消」，沒有多出紀錄。
- [ ] 往下滑：按了金額再往下滑，畫面不會關掉。什麼都沒填時滑得掉。每月預算改了數字也一樣滑不掉。

## 常用分類

- [ ] 從記一筆進去：按一個金額，按「分類」右邊的「編輯」，打開「常用分類」。按「完成」回來，金額還在。
- [ ] 從設定進去：設定按「常用分類」，是往右推進去的，沒有「完成」，按左上角返回。
- [ ] 勾選：勾「早餐」，回到記一筆多一格早餐，排在最後。用它記一筆。
- [ ] 取消勾選：把早餐取消，格子就沒有；剛才那筆還在，分析頁照樣列出早餐。點那筆進去改，格子最後面有早餐而且是選取的。
- [ ] 選好再取消：記一筆選早餐，按「編輯」取消勾選早餐，回來「記下」按不動。
- [ ] 至少留一個：切到收入，取消到剩一個，上面的字變成「至少留一個。」，再點不會取消，手機震一下。
- [ ] 拖曳排序：按住右邊的把手往上往下拖，順不順。拖到清單上下緣會自己捲。放開後記一筆的格子照新順序。
- [ ] 三個動作不打架：點左邊整塊是勾選，點筆是編輯，拖把手不會變成勾選。
- [ ] 一格一格移：點筆進去按「往前移一格」「往後移一格」，順序跟著變。排在最前面的「往前移一格」按不動。
- [ ] 新增分類：取名、選圖示、按「存分類」，記一筆的格子最後多這一格。用它記一筆，明細、分析、匯出都是這個名字。
- [ ] 名字擋下來：打「飲食」會寫「已經有同名的分類」，打九個字會寫「最多 8 個字。」，這兩種「存分類」都按不動。用注音打字，選字前後都正常。
- [ ] 八個字的名字：取一個八個字的，記一筆的格子裡看得完。
- [ ] 改內建的名字與圖示：把「飲食」改成「吃飯」，換一個圖示。以前的飲食全部變成吃飯，數字不變。再新增一個叫「飲食」的會被擋下來。
- [ ] 恢復原本的名字與圖示：改過的內建分類裡有這一列，按了變回來。
- [ ] 刪掉自訂分類：要先問一次。刪完格子沒有它，記過的照樣看得到名字。內建的分類沒有刪除。
- [ ] 恢復預設：先切到支出按「恢復預設」，問的時候寫的是支出。按了之後支出回到原本 12 個，自己新增的變成沒勾，收入那邊不動。
- [ ] 圖示：常用分類從頭捲到尾，再看編輯分類的圖示格，沒有空白的。
- [ ] 重開還在：改過的名字、順序、自己新增的，把 App 關掉再開都還在。
- [ ] 改到一半離開：編輯分類改了名字沒按「存分類」，按返回，名字不會變，也不會問。從記一筆進去的再往下滑一次。這樣可不可以，告訴我。

## 改、刪、復原

- [ ] 記完馬上復原：提示條還在的 5 秒內按「復原」，這筆消失，本月支出扣回去。
- [ ] 修改：點一筆，改金額、分類、日期、備註再記下。明細、小計、本月支出都跟著變。
- [ ] 左滑刪除：往左滑刪掉一筆，提示條寫「已刪除「那筆的標題」」，按「復原」會回來。左滑不會先問。
- [ ] 在修改畫面刪除：點一筆，按右上角「刪除」，要先問一次，按「刪除這筆」才會刪。刪完回到明細，也能復原。
- [ ] 分析頁裡改和刪：從最大的三筆、分類明細點進去改，或在分類明細左滑刪除，數字馬上跟著變。

## 預算

- [ ] 訂預算：分析頁按「訂每月預算」，輸入一個比本月支出高的數字，按「存預算」。分析頁寫「預算還剩 NT$…，每天 NT$…。」；記帳頁本月支出右邊寫「還能花」和數字。
- [ ] 花超過：記一筆讓本月支出超過預算。分析頁寫「多花了 NT$…」，記帳頁右邊改顯示「預算」和數字。
- [ ] 改預算：再訂一個數字，換成新的。切到上個月，不會套用這個月才訂的預算。
- [ ] 不訂預算：進去按「不訂預算」，分析頁變回「訂每月預算」，記帳頁的預算字消失。

## 分析

第一天就能試的：

- [ ] 花了多少：數字跟記帳頁的本月支出一樣。沒有支出時寫「還沒有支出紀錄。」，有紀錄但月份不夠時寫「再有 2 個記完整的月份，就能跟平常比。」
- [ ] 花在哪一類：由多到少，加起來等於本月支出。超過五類時，按「看全部」會展開。點一類進去，筆數和總額對得上。
- [ ] 最大的三筆：這個月滿 10 筆支出才會出現，三筆的合計要對。
- [ ] 最近幾個月：補記一筆以前月份的，這張卡才會出現。這個月的橫條是空心，中間整個月沒記的寫「沒有紀錄」。
- [ ] 切月份：按左右箭頭，數字跟著換。在這個月時右箭頭按不動。

要有兩個記完整的月份才能試（一個月至少 10 筆支出，中間沒有連續超過 7 天的空窗；可以用補記湊）：

- [ ] 跟平常比：7 號以後，這個月也沒有太長的空窗時，第一張卡寫比平常多、少或差不多，橫條上有灰底的平常範圍。
- [ ] 一次性不列入比較：記一筆大額的一次性，總額會變多，「比平常多多少」不變，橫條多一段空心。
- [ ] 觀察：14 號以後，某一類這個月滿 10 筆，而且明顯比平常多或少時，會有「看這 N 筆」的連結，點進去是那一類的明細。同時最多出現一個。
- [ ] 空窗：這個月連續超過 7 天沒記，要寫「中間有幾天沒記，先不跟平常比。」，不寫幾天。
- [ ] 月初回顧：1 到 7 號、上個月滿 10 筆支出時，最上面有上個月的回顧，點了會切到上個月。這一項只要上個月有紀錄就能試。

## 小工具與控制中心

- [ ] 主畫面：加白菜記帳的小工具。加的時候預覽有數字。放好之後的數字跟記帳頁一樣：有訂預算是「還能花」，沒訂是「本月支出」。
- [ ] 點主畫面小工具：打開 App，直接是記一筆。App 整個關掉時點、App 在背景時點，各試一次。
- [ ] 記完會變：記一筆，回主畫面，數字跟著變。改、刪、訂預算也是。
- [ ] 過了午夜、過了月底：不打開 App，數字自己換。月初變成新的一個月。
- [ ] 鎖定畫面：加長方形的和時間上面那一行，字沒有被切掉。點了打開 App。
- [ ] 鎖著的時候：鎖住手機，看數字露不露出來，告訴我看到什麼。到設定 → Face ID 與密碼，把鎖定時允許取用的幾項關掉再看一次，記下是關哪一項才藏起來。
- [ ] 控制中心（iOS 18 以上）：加「記一筆」，按下去打開記一筆。放到動作按鈕也試一次。
- [ ] 填到一半不會被打斷：記一筆填到一半，回主畫面點小工具，剛才填的還在。
- [ ] 外觀：主畫面用深色、單色（Tinted），數字和「記一筆」都看得清楚。
- [ ] 大金額：本月支出六位數時，小工具上的數字沒有被切掉。
- [ ] 清除之後：按「清除所有資料」，小工具不再顯示舊的數字。

## 資料

- [ ] 重開還在：記幾筆，把 App 從多工畫面滑掉再開。紀錄、備註、預算都在。
- [ ] 重開機、更新還在：手機重開機後資料還在；裝新一版 TestFlight 之後也還在。
- [ ] 飛航模式：開飛航模式，記、改、刪、看分析都正常。
- [ ] 過了午夜：晚上記一筆，隔天回到 App，昨天那筆標成「昨天」，新記的算在「今天」。
- [ ] 匯出：設定按「匯出資料」，存到檔案 App，用 Numbers 或 Excel 打開。中文不亂碼，筆數跟 App 一樣，刪掉的不在裡面，改過名字的分類寫現在的名字。沒有紀錄時按不動。

## 設定

- [ ] 列的順序：記帳（常用分類）、一般（外觀、觸覺回饋）、資料（匯出資料、清除所有資料）、關於（蔬菜家族的其他 app、隱私說明）、頁尾。沒有意見回饋、評分、分享、隱私權政策。
- [ ] 外觀：選深色，整個 App 馬上變，記一筆和每月預算那種彈出來的畫面也是深色。選淺色、跟隨系統各試一次。關掉重開，選的還在。
- [ ] 外觀跟隨系統：選跟隨系統，到手機的控制中心切深色，App 跟著切。
- [ ] 觸覺回饋打開：記好一筆、刪一筆、換選分類、勾常用分類，各震一下，種類不同。會不會太多，告訴我。
- [ ] 觸覺回饋關掉：同樣的動作都不震。關掉重開，還是關的。
- [ ] 蔬菜家族的其他 app：列出茄記、豆鍵、蒜日子，按「取得」跳到 App Store 的正確那一頁。回來 App 停在原畫面。
- [ ] 頁尾連結：網站、Facebook、Instagram 各按一次，開的是對的那一頁。
- [ ] 複製版本資訊：長按版本號，出現「已複製版本資訊」。貼到備忘錄，有 App、iOS、機型、語言四行，沒有任何紀錄。

## 看得清楚、按得到

- [ ] 深色：切到深色模式，三個分頁、記一筆、分類明細、訂預算、常用分類、編輯分類各看一眼。字都清楚，橫條、空心條和灰底分得出來。
- [ ] 大字：把文字大小調到輔助使用的大字，同樣的畫面再看一次。字沒有被切掉，「記下」和「記一筆」按得到，分類捲得到最後一個。
- [ ] 單手：用右手、左手各記三筆，拇指按得到所有數字、退格、「記下」。左上角的取消和右上角的刪除如果太遠，記下來告訴我。
- [ ] 小手機：有螢幕比較小的 iPhone 就試一次。記一筆時分類看得到，而且捲得動。
- [ ] VoiceOver：打開 VoiceOver 記一筆。分類會念名稱和有沒有選取，退格會念「退格」，明細會念標題、分類和金額。
- [ ] VoiceOver 常用分類：「分類」右邊的按鈕念「編輯常用分類」。每一列念名字和有沒有選取，筆念「編輯飲食」。在一列上用轉子的動作選「上移」「下移」，順序會變。剩一個時會念「至少留一個。」。
- [ ] VoiceOver 設定：外觀會念現在選的是哪個，觸覺回饋念得出開或關，版本號會提示長按可以複製，頁尾三個連結念得出名字。
- [ ] 按壓：每顆按鈕按下去都會變淡，鍵盤和分類格會稍微縮小。清單裡整列的不縮。
- [ ] 減少動態：手機的輔助使用打開「減少動態效果」。按鈕不縮，總額改成淡入淡出。記一筆、左滑刪除、按復原，看得出是哪一筆變了，下面的列讓位時不會彈。點到露一半的分類格，直接捲到位。

## 清除（最後做）

- [ ] 清除到一半反悔：按「清除所有資料」，兩次詢問各按一次「取消」，資料都還在。
- [ ] 清除所有資料：第一次問的時候有「先匯出」，按了會打開匯出。再按一次清除，按「繼續」還會再問一次，按「全部刪除」才真的刪。記帳頁回到「還沒有紀錄」，預算也沒了。常用分類回到原本的 16 個，自己新增的、改過的名字都不見，外觀回到跟隨系統，觸覺回饋回到打開。重開 App 還是空的。
