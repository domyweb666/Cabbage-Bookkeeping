# TestFlight 實測清單

規格 9.5。這些只能在真的手機上驗，CI 測不到。每一項寫了怎麼做、看到什麼算過。

做之前先確認設定頁最上面沒有「示範模式」那一行。有的話代表建置時沒帶到 Supabase 的設定。

## 記

- [ ] **首次開啟到第一筆入帳**　刪掉 App 重裝，打開。不該出現教學或註冊畫面，直接看到三個範例句，鍵盤自動彈出。打「麥當勞 188」送出。從點開 App 到時間軸出現這筆，8 秒內算過。
- [ ] **語音記帳**　按麥克風，第一次會問麥克風和語音辨識權限。說「午餐便當一百二」。講的時候輸入框要即時出現文字，停止後文字留在輸入框可以改。送出後入帳，10 秒內算過。
- [ ] **語音：權限被拒**　到 iOS 設定把麥克風權限關掉，回 App 按麥克風。要看到說明文字告訴你去哪裡打開，App 不能當掉。
- [ ] **語音：講超過 30 秒**　按麥克風後一直講。30 秒到要自動停，已辨識的文字留著。
- [ ] **連續快速記三筆**　連打三句各自送出，不等前一筆回來。三筆都要入帳，順序跟輸入的一樣。
- [ ] **一句多筆**　打「早餐 65，中午便當 120，晚上火鍋 450」。出現三筆，今天的小計多 635。
- [ ] **需要確認**　打「買電腦 45000」。底部升起確認卡，寫著金額超過門檻。改分類後按全部確認，入帳。
- [ ] **收入**　打「薪水 52000」。要先出現確認卡，不會直接入帳。
- [ ] **看不懂**　打「午餐花了一些錢」。輸入列上方出現提示，原話留在輸入列。

## 離線

- [ ] **飛航模式記帳**　開飛航模式，打「咖啡 80」送出。時間軸出現淡色的「待處理」，畫面上方有離線說明。關掉飛航模式，幾秒內自動變成正式的一筆。
- [ ] **離線時跨日**　飛航模式下記一筆，把這筆留到隔天再連線。入帳的日期要是輸入的那天，不是連線的那天。
- [ ] **離線時不能編輯刪除**　飛航模式下點任一筆、左滑。都不該有反應。

## 改

- [ ] **復原**　記一筆後，5 秒內按底部的「復原」。這筆消失，本月支出扣回去。
- [ ] **刪除後復原**　左滑刪除一筆，按「復原」。這筆回來。
- [ ] **編輯分類後自動套用**　記「全聯 320」，點進去把分類改成購物後儲存。再記「全聯 150」。第二筆要自動是購物。
- [ ] **手動新增**　長按送出鍵，填一筆存檔。出現在時間軸。

## 問

問之前先有幾天的資料。每一題的數字拿去跟本月概覽或自己加總對一下。

- [ ] 這個月花多少？
- [ ] 這個月外食花多少？
- [ ] 上禮拜花最多的是哪一筆？
- [ ] 這個月比上個月多花多少？
- [ ] 花最多的分類是哪個？
- [ ] **依據**　任一張回答卡點「依據：N 筆」。列出來的交易加起來要等於回答裡的數字。
- [ ] **問沒有的東西**　問「寵物花多少？」（沒記過寵物）。要回答查不到，不能編數字。

## 概覽與設定

- [ ] **本月概覽**　點頂部的本月支出。總支出、總收入、分類長條圖都有。記一筆「機車維修 4650」之後，「扣掉一次性支出後的日常開銷」不該把它算進去。切到上個月再切回來，數字正確。
- [ ] **關閉直接入帳**　設定裡關掉直接入帳，記「麥當勞 188」。要先出現確認卡。
- [ ] **調低門檻**　門檻改成 NT$1,000，記「買衣服 1280」。要先出現確認卡。
- [ ] **深色模式**　切到深色模式，主畫面、確認卡、編輯、概覽、設定各看一眼，文字都讀得清楚。

## 帳號與資料

- [ ] **綁定 Apple ID**　設定裡按「透過 Apple 繼續」，完成後顯示已綁定 Apple ID。
- [ ] **重裝後取回**　刪掉 App 重裝，先不要記任何東西，到設定按「透過 Apple 繼續」。要顯示已經取回資料，回主畫面看到之前的紀錄。重裝後如果一打開紀錄就都在，也算過（iOS 有時會保留登入狀態）。
- [ ] **手機上有新紀錄時不會被蓋掉**　重裝後先記一筆，再到設定按「透過 Apple 繼續」。要看到提醒說這個 Apple ID 已經有備份、手機上還有新紀錄，剛記的那筆還在。
- [ ] **匯出**　設定裡按匯出 CSV，存到檔案 App，用 Numbers 或 Excel 打開。中文不能亂碼，筆數跟 App 裡一樣。
- [ ] **刪除所有資料**　設定裡按刪除所有資料並確認。時間軸清空，本月支出歸零。重開 App 還是空的。
