# TestFlight 實測清單

這些要在真的手機上試。每一項寫了怎麼做、看到什麼算過。

測試資料要清掉的話，最後再做「清除所有資料」那兩項。

## 記

- [ ] 第一次打開：刪掉 App 重裝再打開。沒有教學、不用登入、不跳權限，直接看到「還沒有紀錄」和底部的「記一筆」。
- [ ] 記一筆：按「記一筆」，按 1、8、8，點「飲食」，按「記下」。明細最上面出現這筆，提示條寫「記好了。飲食這個月共 NT$188」，本月支出多 188。從點開 App 到記好，8 秒內算過。
- [ ] 沒填完不能記：只按金額，或只點分類，「記下」都按不動。
- [ ] 金額鍵盤：「00」和退格都正常。一直按，最多到八位數。
- [ ] 連續記三筆：記完一筆馬上再記兩筆，三筆都在，最新的在最上面。
- [ ] 收入：切到「收入」，分類換成薪水、獎金、投資、其他收入。記薪水 42000。明細是綠色的 +42,000，本月支出不變。
- [ ] 切換收入和支出：選好飲食後切到「收入」，再切回「支出」，飲食要變成沒選。
- [ ] 備註：點備註，數字鍵盤讓位給系統鍵盤，用注音打「加油」，按「完成」，數字鍵盤回來。記下後明細標題是「加油」，下面的小字是分類。
- [ ] 不填備註：明細標題直接是分類名。
- [ ] 一次性：支出點「一次性」，下面出現「跟平常比的時候，不算這一筆。」記下後明細有「一次性」。切到收入時沒有這顆。
- [ ] 補記：日期選昨天，這筆排到「昨天」。明天以後的日期選不到。
- [ ] 補記上個月：日期選上個月，記一筆飲食。提示條寫「記好了。飲食 NT$…」，沒有「這個月共」，本月支出不變。
- [ ] 取消：填到一半按「取消」，沒有多出紀錄。

## 改、刪、復原

- [ ] 記完馬上復原：提示條還在的 5 秒內按「復原」，這筆消失，本月支出扣回去。
- [ ] 修改：點一筆，改金額、分類、日期、備註再記下。明細、小計、本月支出都跟著變。
- [ ] 左滑刪除：往左滑刪掉一筆，提示條寫「已刪除」，按「復原」會回來。
- [ ] 在修改畫面刪除：點一筆，按右上角「刪除」，要先問一次。刪完回到明細，也能復原。
- [ ] 分析頁裡改和刪：從最大的三筆、分類明細點進去改，或在分類明細左滑刪除，數字馬上跟著變。

## 預算

- [ ] 訂預算：分析頁按「訂每月預算」，輸入一個比本月支出高的數字，按「存」。分析頁寫出還剩多少、剩幾天、一天多少；記帳頁本月支出下面寫「還能花 NT$…」。
- [ ] 花超過：記一筆讓本月支出超過預算。分析頁寫「多花了 NT$…」，記帳頁改顯示「預算 NT$…」。
- [ ] 改預算：再訂一個數字，換成新的。切到上個月，不會套用這個月才訂的預算。
- [ ] 不訂預算：進去按「不訂預算」，分析頁變回「訂每月預算」，記帳頁的預算字消失。

## 分析

第一天就能試的：

- [ ] 花了多少：數字跟記帳頁的本月支出一樣。沒有支出時寫「還沒有支出紀錄。」，有紀錄但月份不夠時寫「再有 2 個記完整的月份，就能跟平常比。」
- [ ] 花在哪一類：由多到少，加起來等於本月支出。超過五類時，按「看全部」會展開。點一類進去，筆數和總額對得上。
- [ ] 最大的三筆：這個月滿 10 筆支出才會出現，三筆的合計要對。
- [ ] 最近幾個月：補記一筆以前月份的，這張卡才會出現。這個月的橫條是空心，中間整個月沒記的寫「沒有紀錄」。
- [ ] 切月份：按左右箭頭，數字跟著換。在這個月時右箭頭按不動。

要有兩個記完整的月份才能試（一個月至少 10 筆支出，中間沒有連續超過 7 天的空窗；可以用補記湊）：

- [ ] 跟平常比：7 號以後，這個月也沒有太長的空窗時，第一張卡寫比平常多、少或差不多，橫條上有灰底的平常範圍。
- [ ] 一次性不列入比較：記一筆大額的一次性，總額會變多，「比平常多多少」不變，橫條多一段空心。
- [ ] 觀察：14 號以後，某一類這個月滿 10 筆，而且明顯比平常多或少時，會有「看這 N 筆」的連結，點進去是那一類的明細。同時最多出現一個。
- [ ] 空窗：這個月連續超過 7 天沒記，要寫「中間有 N 天沒有紀錄，先不跟平常比。」
- [ ] 月初回顧：1 到 7 號、上個月滿 10 筆支出時，最上面有上個月的回顧，點了會切到上個月。這一項只要上個月有紀錄就能試。

## 資料

- [ ] 重開還在：記幾筆，把 App 從多工畫面滑掉再開。紀錄、備註、預算都在。
- [ ] 重開機、更新還在：手機重開機後資料還在；裝新一版 TestFlight 之後也還在。
- [ ] 飛航模式：開飛航模式，記、改、刪、看分析都正常。
- [ ] 過了午夜：晚上記一筆，隔天回到 App，昨天那筆標成「昨天」，新記的算在「今天」。
- [ ] 匯出：設定按「匯出資料」，存到檔案 App，用 Numbers 或 Excel 打開。中文不亂碼，筆數跟 App 一樣，刪掉的不在裡面。沒有紀錄時按不動。

## 看得清楚、按得到

- [ ] 深色：切到深色模式，三個分頁、記一筆、分類明細、訂預算各看一眼。字都清楚，橫條、空心條和灰底分得出來。
- [ ] 大字：把文字大小調到輔助使用的大字，同樣的畫面再看一次。字沒有被切掉，「記下」和「記一筆」按得到，分類捲得到最後一個。
- [ ] 單手：用右手、左手各記三筆，拇指按得到所有數字、退格、「記下」。左上角的取消和右上角的刪除如果太遠，記下來告訴我。
- [ ] 小手機：有螢幕比較小的 iPhone 就試一次。記一筆時分類看得到，而且捲得動。
- [ ] VoiceOver：打開 VoiceOver 記一筆。分類會念名稱和有沒有選取，退格會念「退格」，明細會念標題、分類和金額。

## 清除（最後做）

- [ ] 清除到一半反悔：按「清除所有資料」，兩次詢問各按一次「取消」，資料都還在。
- [ ] 清除所有資料：第一次問的時候有「先匯出」，按了會打開匯出。再按一次清除，按「繼續」還會再問一次，按「全部刪除」才真的刪。記帳頁回到「還沒有紀錄」，預算也沒了。重開 App 還是空的。
