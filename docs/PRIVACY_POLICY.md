## 我們收集什麼

**你輸入的記帳內容。** 你打的或講的每一句話（原話），以及整理出來的金額、日期、品項、商家、分類、標籤和備註。

**帳號識別碼。** 第一次打開 App 時會自動建立一個匿名帳號，只有一組隨機編號，不含姓名、電話或 Email。如果你選擇用 Apple ID 備份，我們會收到 Apple 提供的帳號識別碼，用來讓你換手機後取回資料；我們沒有向 Apple 要求你的姓名和 Email。

**使用量紀錄。** 每次請 AI 整理或回答時，會記下時間、用了哪個模型、用了多少字數額度。這是用來控制成本和設定每日上限，不含你輸入的內容。

我們不收集位置、通訊錄、照片、廣告識別碼，也不做跨 App 追蹤。

## 語音

用語音記帳時，聲音由 Apple 的語音辨識服務轉成文字，處理方式適用 Apple 的隱私權政策。App 不保存錄音，只使用轉出來的文字。

## AI 服務會看到什麼

App 用 Anthropic 的 Claude 把你的話整理成紀錄、回答你的問題。傳過去的內容只有：

- 你這次輸入的那一句話。
- 分類清單，以及你改過分類後留下的習慣（例如「麥當勞→飲食」）。
- 你提問時，資料庫查出來的統計結果與明細。

不會傳你的帳號識別碼、Apple ID 或裝置資訊。Anthropic 如何處理透過 API 收到的資料，請見其商業條款與隱私權政策（需作者補充：連結，並確認目前的資料保留與訓練使用條款）。

## 資料存在哪裡

紀錄存在 Supabase 提供的雲端資料庫（需作者補充：專案所在區域）。資料庫設定了逐列的存取限制，每個帳號只讀得到自己的資料。你的手機上另外留一份，方便離線時查看。

## 保存多久

資料會一直保存到你刪除為止。你在 App 裡刪除單筆紀錄後，可以馬上復原；這類紀錄在資料庫中標記為已刪除，不會出現在任何統計裡。使用「刪除所有資料」則會從資料庫真正移除，無法復原。

## 你可以做的事

- **匯出**：設定 → 匯出 CSV，取得全部紀錄。
- **刪除**：設定 → 刪除所有資料，雲端和手機上的紀錄、原話、分類習慣都會刪掉。
- **停用**：刪除 App 即可。匿名帳號沒有綁定 Apple ID 時，刪除 App 後資料無法取回。
