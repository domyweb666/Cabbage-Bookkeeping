# 不能改的字串

上架之後改了，使用者放好的小工具會失效、讀不到舊資料，或 Apple 那邊對不上。

| 是什麼 | 值 | 寫在哪裡 | 改了會怎樣 |
|---|---|---|---|
| App 的 Bundle ID | `org.domyweb.baicai` | `ios/project.yml`、`ios/ci/asc_api.mjs`、`ios/ci/ExportOptions.plist` | 變成另一個 app |
| 小工具的 Bundle ID | `org.domyweb.baicai.widget` | 同上 | 簽章會壞，放好的小工具不見 |
| App Group | `group.org.domyweb.baicai` | `ios/project.yml` 兩處、`ios/Shared/WidgetBridge.swift`、`ios/ci/asc_api.mjs` | 小工具讀不到數字 |
| 小工具的 kind | `org.domyweb.baicai.widget.left` | `ios/Shared/WidgetBridge.swift` | 主畫面、鎖定畫面放好的那一塊失效 |
| 控制中心按鈕的 kind | `org.domyweb.baicai.control.add` | `ios/Shared/WidgetBridge.swift` | 控制中心放好的那一顆失效 |
| 網址 | `baicai://entry` | `ios/Shared/WidgetBridge.swift`、`ios/project.yml` | 小工具點了打不開記一筆 |
| 資料庫的名字 | `Baicai` | `ios/AIFinance/Data/LocalStore.swift` | 會去讀另一個檔，舊紀錄看起來不見了 |

分類的編號也不能改，看 [DECISIONS.md](DECISIONS.md) 第 37 點。
