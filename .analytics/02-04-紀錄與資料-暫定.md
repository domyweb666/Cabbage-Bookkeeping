## 資料結構（3-4）

程式：`ios/Packages/FinanceCore/Sources/FinanceCore/Models.swift`。

六條原則對照：只存每一筆，總數當場算；`createdAt` 存世界標準時間、另存 `timeZone`；修改把舊值留在 `revisions`，刪除標 `deletedAt`；分類用固定編號引用；沒有計時；每筆有 `schemaVersion`（現在是 1）。

| 情況 | 怎麼存 | 分析怎麼算 |
|---|---|---|
| 半夜 1 點的宵夜 | 日期是當天，可以自己改昨天 | 用日期。換日用午夜，要對得上發票和帳單（書的起點是凌晨 4 點，這裡不用） |
| 出國換時區 | 日期照當地，另存時區 | 用存下來的日期，不重算 |
| 補記上個月 | 日期是上個月 | 算進上個月，上個月的比較跟著重算 |
| 改金額、分類、日期 | 舊值留在 revisions | 用新值 |
| 刪除、復原 | 標記，可以拿掉標記 | 不算 |
| 退款 | 記收入，或改原本那筆的金額 | 照記的算。之後要不要做退款，等真的有人問 |
| 分期 | 每期一筆 | 照日期算 |
| 外幣 | 自己換算成台幣再記 | 不處理匯率 |
| 一次性大筆 | 標一次性 | 總額算，跟平常比不算 |
| 整段沒記 | 沒有資料 | 不當零。超過 7 天的空窗，那個月不比，也不當別人的比較對象 |
| 改預算 | 新增一筆，從這個月起 | 舊月份用舊預算 |
| 資料庫打不開 | 不寫入 | 顯示錯誤，不默默改用記憶體 |

匯出：設定裡一鍵匯出 CSV，含編號、記錄時間、時區。刪除：設定裡全部清除，問兩次。
