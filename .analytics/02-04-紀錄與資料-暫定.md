## 資料結構（3-4）

程式：`ios/Packages/FinanceCore/Sources/FinanceCore/Models.swift`，分類在同一個資料夾的 `Categories.swift`（內建目錄）和 `CategoryBook.swift`（這支手機的設定）。

六條原則對照：只存每一筆，總數當場算；`createdAt` 存世界標準時間、另存 `timeZone`；修改把舊值留在 `revisions`，刪除標 `deletedAt`；分類用固定編號引用；沒有計時；每筆有 `schemaVersion`（現在是 2：多了 `fixed` 和 `estimate` 兩欄，都可以是空的，1 的紀錄照樣讀得到）。

分類的結構：

- 紀錄只存分類編號，名字和圖示當場找。內建分類支出 67、收入 17，編號固定，只往後加。
- 分類的設定整份存一列，也有 `schemaVersion`（1）：顯示哪些與順序（支出、收入各一份）、改過的內建名字與圖示（覆蓋）、自訂分類。
- 自訂分類存編號、收支、名字、圖示、`createdAt`、`deletedAt`、`schemaVersion`。
- 跟「修改留舊值」不同的一處：改名和換圖示不留舊值，換順序和勾選也不留歷史。它們不影響任何數字。

| 情況 | 怎麼存 | 分析怎麼算 |
|---|---|---|
| 半夜 1 點的宵夜 | 日期是當天，可以自己改昨天 | 用日期。換日用午夜，要對得上發票和帳單（書的起點是凌晨 4 點，這裡不用） |
| 出國換時區 | 日期照當地，另存時區 | 用存下來的日期，不重算 |
| 補記上個月 | 日期是上個月 | 算進上個月，上個月的比較跟著重算 |
| 改金額、分類、日期 | 舊值留在 revisions | 用新值 |
| 刪除、復原 | 標記，可以拿掉標記 | 不算 |
| 退款 | 記收入，或改原本那筆的金額 | 照記的算。之後要不要做退款，等真的有人問 |
| 分期 | 每期一筆 | 照日期算 |
| 外幣 | 自己換算成台幣再記 | 不處理匯率 |
| 取消勾選某個常用分類 | 只改記帳畫面顯示哪些格子，紀錄不動 | 照算，分析頁照樣列出 |
| 中途把「飲食」改記成「早餐」「午餐」 | 兩邊各是各的分類 | 分開算。換分法之後那幾個月，分類的平常範圍會暫時沒有，要重新累積 2 個月 |
| 新增自訂分類 | 自己的編號，收支定了不能改 | 跟內建一樣算 |
| 改分類的名字、圖示 | 內建存覆蓋，自訂直接改。紀錄不動 | 還是同一類，以前的月份也用新名字 |
| 換順序、恢復預設 | 只改設定 | 不影響，分析頁照金額排 |
| 刪掉自訂分類 | 標 `deletedAt`，名字還在 | 照算、照列原本的名字 |
| 刪掉再取一個同名的 | 兩個編號 | 分開算，分析頁會有兩列同名的 |
| 找不到分類（編號對不到） | 紀錄上的編號不改 | 支出算在「其他」，收入算在「其他收入」，金額照算 |
| 分類設定讀不出來 | 停用寫入 | 跟紀錄讀不出來一樣處理 |
| 一次性大筆 | 標一次性 | 總額算，跟平常比不算 |
| 每月固定到期 | 自動記一筆，日期是到期那天，`fixed` 記哪一項、哪一期 | 總額、分類、還能花照算。不算「有在記帳」：不補空窗，不算進 10 筆門檻 |
| 每年固定到期 | 同上，另外標一次性 | 總額算；預算不整筆扣，每個月扣十二分之一；跟平常比不算 |
| 好幾個月沒打開 | 打開那次一次補齊，日期是各期到期那天 | 照各自的日期算 |
| 刪掉自動記的那筆 | 標記，那一期不會再記 | 不算 |
| 改固定支出的金額 | 舊金額留在 `revisions`，記好的不動 | 下一期用新金額；以前月份的分攤用當時的金額 |
| 改固定支出的日子 | 從今天起算，不回頭補 | 這一期記過就不再記 |
| 刪固定支出 | 標 `endedOn`，記好的不動 | 那個月起不再先留 |
| 固定支出設的那天已經過了這個月的日子 | 這個月不記 | 下個月開始，畫面上寫明下一次記在哪天 |
| 每月改成每年 | 不給改 | 刪掉重設 |
| 補一個大概的數字 | 一筆支出，分類「其他」，日期是那段的最後一天，`estimate` 記頭尾兩天 | 總額、還能花照算；那幾天不算空窗；不進最大的三筆，不算進分類的平常和觀察；跟前幾個月同期比時照天數分 |
| 大概的那筆改日期到那段以外，或改成收入 | `estimate` 拿掉 | 變成普通的一筆 |
| 整段沒記 | 沒有資料 | 不當零。超過 7 天的空窗，那個月不比，也不當別人的比較對象；補過大概就可以 |
| 改預算 | 新增一筆，從這個月起 | 舊月份用舊預算 |
| 資料庫打不開 | 不寫入 | 顯示錯誤，不默默改用記憶體 |

匯出：設定裡一鍵匯出 CSV，含編號、記錄時間、時區。分類寫匯出當下的名字，不含分類編號和分類的設定。刪除：設定裡全部清除，問兩次，分類的設定一起清。

舊資料：沒有。AI 版沒有發布過，也沒有人存過真的紀錄。
